# 设计范式

React `@ant-design/x@2.0.0` 的 `spec` 目录是 RICH 设计文，不是组件 API。Vue 站点不复制这些长文，原文在 React 文档：

- [RICH 简介](https://x.ant.design/docs/spec/introduce-cn)
- 唤醒、意图、表达、确认、反馈各篇都在同一站点的 spec 目录

组件页已经按这套结构铺开：Welcome / Prompts（唤醒）、Sender / Attachments / Suggestion / FileCard（表达）、Think / ThoughtChain / Sources（确认）、Actions（反馈）、Bubble / Conversations（会话）。

和实现对齐时以组件页和 [从 v1 到 v2](/development/migration-v2) 为准。设计文里的示意图不会在这里重做一份。
