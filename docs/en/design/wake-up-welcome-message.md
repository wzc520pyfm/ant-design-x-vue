# Wake · Welcome message

![](https://mdn.alipayobjects.com/huamei_iwk9zp/afts/img/A*DMkuSr4HMfEAAAAAAAAAAAAADgCCAQ/fmt.webp)

When users first step into the world of AI products, they can quickly understand and unlock AI's powerful capabilities and specific uses through welcome recommendations.

## Design goals

Welcome & prompt components are suitable for the [AI Awakening Phase], allowing users new to AI products to quickly understand what AI can do, clearly conveying the intended scope and expected functions of AI. Using appropriate welcome and recommendation components can effectively reduce users' learning costs, enabling users to quickly understand AI's capabilities and master the correct usage methods, enabling rapid understanding and smooth start.

---

## 👋 Welcome component

Use vivid copy and intuitive introductions to quickly help users understand AI products, reducing learning costs and confusion; Carefully present visuals to attract users' attention, creating a warm, convenient, and surprising initial experience that enhances user satisfaction and loyalty with AI products.

> **Note:** Welcome components usually come with recommended components suitable for different scenarios.

## 👂 Prompt components

<ImagePreview>
<img class="preview-img no-padding" src="https://mdn.alipayobjects.com/huamei_iwk9zp/afts/img/A*TGlzSpZj9a0AAAAAAAAAAAAADgCCAQ/fmt.webp">
</ImagePreview>

Based on user behavior, preferences, and historical data, it accurately recommends personalized content and services, improving the efficiency of users discovering valuable content and enhancing interaction and stickiness between users and products. AI prompt components continuously optimize recommendation results as user data accumulates and evolves to meet users' evolving needs.

- **Personalized Recommendations:** Improve the efficiency of users in discovering valuable content.
- **Continuous Optimization:** Dynamically adjust recommendations as user data accumulates to meet changing user needs.

> **Note:** Prompt components are usually used together with welcome components.
