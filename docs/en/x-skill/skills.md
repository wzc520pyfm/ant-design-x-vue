# Skills List

> 中文：[技能列表](/x-skill/skills)

Ant Design X Vue provides the following core skills to help you build AI conversation apps. English texts live in `packages/x-skill/skills/`; Chinese texts live in `packages/x-skill/skills-zh/`.

| Skill | Covers |
| --- | --- |
| [`use-x-chat`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills/use-x-chat) | Vue `useXChat` / `useXConversations`, and mapping into `Bubble.List` |
| [`x-chat-provider`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills/x-chat-provider) | Built-in and custom `AbstractChatProvider` |
| [`x-request`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills/x-request) | `XRequest` (instance `run` / `abort`; Providers need `manual: true`) |
| [`x-markdown`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills/x-markdown) | `XMarkdown` streaming, plugins, component maps |
| [`x-card`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills/x-card) | A2UI with `XCard.Box` / `XCard.Card` |
| [`x-components`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills/x-components) | UI components such as `Bubble`, `Sender`, `Folder` |

See the [Introduction](/en/x-skill/introduce) for install steps and [Prompt Templates](/en/x-skill/prompt) for ready-to-use prompts.
