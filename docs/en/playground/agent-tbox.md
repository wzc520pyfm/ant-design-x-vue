# Tbox

The layout aligns with React 2.10's agent-tbox: conversation bar, Welcome, two sets of prompts, Thinking, ThoughtChain, and Sender. In React, `tbox-nodejs-sdk` is used to call Baibaoxiang in Node, and this package cannot be included in browser documents, so replies are generated by the local Provider.
