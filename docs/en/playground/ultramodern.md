# Ultramodern

Matches React `@ant-design/x` 2.10 ultramodern: conversations, empty-state title, bubbles, `slotConfig`, and a Sender with a deep-think switch. Uses the same public glm demo API as React 2.10 (`glm-4.5-flash`), embedded in the docs shell.
