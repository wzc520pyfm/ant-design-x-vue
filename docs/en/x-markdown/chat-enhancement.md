# Chat Think · Sources

`components` can hand over custom tags to existing conversation components. `think` corresponds to [Think](/en/component/think), citation lists correspond to [Sources](/en/component/sources), ThoughtChain corresponds to [ThoughtChain](/en/component/thought-chain).

:::demo-v2 renders the `think` tag as Think.

:::

## Sources

:::
