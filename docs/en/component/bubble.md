### GPT visualization

Render charts generated by the model in `contentRender` using [`@antv/gpt-vis`](https://github.com/antvis/GPT-Vis). The `vis` code block in the browser is handled with `new GPTVis({ container }).render()`, and `destroy()` is called when the component is unmounted; server-side rendering does not create a canvas.

:::demo-v2 Use `@antv/gpt-vis` to draw Haidilao delivery revenue curves inside the bubble. Re-Render will re-stream the output.

bubble/gpt-vis

:::

## API

### Bubble

| Prop | Description | Type | Default | Version |
| --- | --- | --- | --- | --- |
| avatar | Display avatar | VNode \| (content, info) => VNode | - | |
| classNames | Semantic class names | Record\<SemanticDOM, string\> | - | |
| content | Chat content | ContentType | - | |
| contentRender | Custom rendered content | (content: ContentType, info: Info) => VNode | - | - |
| editable | Editable or not | boolean \| EditableBubbleOption | false | - |
| extra | Extra Content | VNode | (content, info) => VNode | - | - |
| footer | Footer Content | VNode | (content, info) => VNode | - | |
| footerPlacement | Footer Position | `outer-start` | `outer-end` | `inner-start` | `inner-end` | `outer-start` | - |
| header | Header Content | VNode | (content, info) => VNode | - | |
| loading | Chat Content Loading State | boolean | false | |
| placement | Message Position | `start` | `end` | `start` | |
| shape | Bubble Shape | `default` | `round` | `corner` | `default` | Added default in v2 |
| streaming | Whether Streaming | boolean | false | - |
| styles | Semantic styles | Record\<SemanticDOM, CSSProperties\> | - | |
| typing | Typing Animation Configuration | boolean | BubbleAnimationOption | Function | false | Enhanced in v2 |
| variant | Bubble Style Variant | `filled` | `borderless` | `outlined` | `shadow` | `filled` | |
| loadingRender | Custom Render Loading Content | () => VNode | - | |
| messageRender | Custom Render Content (Deprecated, please use contentRender) | (content: ContentType) => VNode | - | |
| onTyping | Callback during animation execution | (rendererContent: string, currentContent: string) => void | - | - |
| onTypingComplete | Callback when animation ends | (content?: string) => void | - | |
| onEditConfirm | Callback when editing is confirmed | (content: string) => void | - | - |
| onEditCancel | Callback when editing is canceled | () => void | - | - |

### BubbleAnimationOption

| Prop | Description | Type | Default |
| --- | --- | --- | --- |
| effect | Type of animation effect | `typing` \| `fade-in` | `fade-in` |
| step | Content step unit, array format for random range | number \| [number, number] | 6 |
| interval | Animation trigger interval | number | 100 |
| keepPrefix | Whether to keep common prefix when restarting animation | boolean | true |

### EditableBubbleOption

| Prop | Description | Type | Default |
| --- | --- | --- | --- |
| editing | Whether in edit mode | boolean | false |
| okText | Text for confirm button | VNode \| string | Confirm |
| cancelText | Text for cancel button | VNode \| string | Cancel |
