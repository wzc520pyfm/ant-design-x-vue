# Overview

`ant-design-x-vue` is the community Vue implementation of `@ant-design/x`. Components are grouped according to RICH interaction phases, in the same order as the React component pages.

:::demo

overview/basic

:::

Data flow is in [X SDK](/en/x-sdk/introduce), rich text is in [X Markdown](/en/x-markdown/introduce). Grouping is consistent with component exports of `@ant-design/x@2.10.0`.
