# Introduction

`ant-design-x-vue` provides AI interface components, grouped the same as the React `@ant-design/x@2.0.0` component pages: General, Wake-up, Expression, Confirmation, Feedback, Others.

Installation and integration in Vite are written in [Development](/en/development/introduce). Model data flow is in [X SDK](/en/x-sdk/introduce), Markdown in [X Markdown](/en/x-markdown/introduce). Independent `CodeHighlighter`, `Mermaid`, and `Folder` components are provided (aligned with React 2.10); Markdown plugins `HighlightCode` / `Mermaid` are still available.
