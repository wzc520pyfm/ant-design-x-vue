# 图表 Mermaid · AntV

语言是 `mermaid` 的围栏代码可以交给 `Mermaid` 组件，在浏览器里画图。服务端先显示源码。步骤在 [插件 · Mermaid](/x-markdown/plugins)。

AntV 图表和 GPT-Vis 没有打进这个包。需要那套可视化时看 [GPT-Vis](https://github.com/antvis/GPT-Vis)。React 文档把 Mermaid 和 AntV 写在一起：[https://x.ant.design/x-markdowns/data-display-cn](https://x.ant.design/x-markdowns/data-display-cn)。
