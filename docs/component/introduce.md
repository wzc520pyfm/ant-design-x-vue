# 介绍

`ant-design-x-vue` 提供 AI 界面组件，分组和 React `@ant-design/x` 的组件页相同：通用、唤醒、表达、确认、反馈、其他。

安装和在 Vite 里接入写在 [研发](/development/introduce)。模型数据流在 [X SDK](/x-sdk/introduce)，Markdown 在 [X Markdown](/x-markdown/introduce)。

下面这些 React 组件本仓库没有对等实现，侧栏保留条目并单独说明：

- [CodeHighlighter](/component/code-highlighter)
- [Folder](/component/folder)
- [Mermaid](/component/mermaid)（独立组件；X Markdown 里可以渲染 mermaid 代码块）

React 组件介绍：[https://x.ant.design/components/introduce-cn](https://x.ant.design/components/introduce-cn)。
