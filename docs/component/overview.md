# 总览

`ant-design-x-vue` 是 `@ant-design/x` 的 Vue 实现。组件按 RICH 的交互阶段分组，顺序和 React 组件页一致。

::: tip 文档版本
这里是 **2.x**。页头可以切到 1.x 站点。Markdown、SDK、设计和样板间在顶栏各自一栏，不再塞进组件侧栏。
:::
