# RICH 设计范式简介

RICH 是 Ant Design X 的设计范式：Role（角色）、Intention（意图）、Conversation（会话）、Hybrid UI（混合界面）。Vue 组件按这四段来分组，这栏只保留栏目和每篇在说什么。

示意图和长文在 React 文档：[RICH 设计范式简介](https://x.ant.design/docs/spec/introduce-cn)。这里不重画一套。

## 和组件的对应

- 唤醒：Welcome、Prompts
- 表达：Attachments、Sender、Suggestion
- 确认：Think、ThoughtChain
- 反馈：Actions、FileCard、Sources
- 会话容器：Bubble、Conversations
