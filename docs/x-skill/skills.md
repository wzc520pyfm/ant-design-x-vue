# 技能列表

Ant Design X Vue 提供以下核心技能，帮助你快速构建 AI 对话应用。英文正文在 `packages/x-skill/skills/`，中文正文在 `packages/x-skill/skills-zh/`（推荐中文环境使用）。

| Skill | 内容 |
| --- | --- |
| [`use-x-chat`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills-zh/use-x-chat) | Vue 版 `useXChat` / `useXConversations`，以及映射到 `Bubble.List` |
| [`x-chat-provider`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills-zh/x-chat-provider) | 内置与自定义 `AbstractChatProvider` |
| [`x-request`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills-zh/x-request) | `XRequest`（实例上的 `run` / `abort`，Provider 必须 `manual: true`） |
| [`x-markdown`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills-zh/x-markdown) | `XMarkdown` 流式渲染、插件、组件映射 |
| [`x-card`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills-zh/x-card) | A2UI 与 `XCard.Box` / `XCard.Card` |
| [`x-components`](https://github.com/wzc520pyfm/ant-design-x-vue/tree/dev/packages/x-skill/skills-zh/x-components) | `Bubble`、`Sender`、`Folder` 等 UI 组件 |

安装方式见 [介绍](/x-skill/introduce)。调用示例见 [Prompt 模板](/x-skill/prompt)。
